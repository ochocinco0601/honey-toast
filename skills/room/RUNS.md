# Room runs

The ledger. A room that is not scored is a room nobody can tell is working.

**Fill the pre-answer column BEFORE the seats are spawned.** A pre-answer written after
a report arrives is not a pre-answer, and a run recorded that way is noise in the one
place that is supposed to be signal.

**The falsifier this table exists to expose:** if the reports keep coming back MATCHED,
the value is in asking the questions, not in the separate contexts — and the honest
product is a short checklist rather than a room. You will only notice that if these
rows are filled in honestly.

| # | Date | Target | Seat | Pre-answer (frozen before spawn) | What came back | MATCHED / DIFFERED | Disposition | Changed |
|---|---|---|---|---|---|---|---|---|
| 1 | | | | | | | | |

**Column notes**

- **Target** — the artifact or decision the room was convened on, as a path.
- **Seat** — one row per seat, so a run of four seats is four rows.
- **Disposition** — `acted` · `user's call` · `back to a seat` · `to the record` ·
  `declined`. Never blank. A declined finding carries its reason in the same cell.
- **Changed** — the commit SHA, or `nothing`. Score on the commit, not on the working
  tree; a tree under active edit has no defined state.
