    About this video

    What GitHub Copilot in VS Code is, what you can use it for, what each training teaches, and which to start with.

    GitHub Copilot is an AI assistant built into Visual Studio Code, Microsoft's editor for code and other files. You open a folder in VS Code and type your request in the chat, in plain language. Copilot can read the files in that folder, create new ones, edit existing ones, and run commands on your computer to complete the task. You don't need to know how to code to use it.

    You might ask it to summarize a set of meeting notes, make sense of documents someone handed you, or explain code you didn't write. By default, Copilot asks for your approval before it runs a command that could change something on your computer. And if you don't like the edits it made to your files, you can undo them.

    For most tasks, asking is all you need. These trainings start there. Then they show you how to set Copilot up ahead of time, so you don't have to repeat the same instructions, and so it can use information from outside your folder.

    The first training, Getting started, covers the basics: making a request, changing or undoing what Copilot did, and having it explain code. It also shows you how to give Copilot instructions that apply to everything in a folder, called custom instructions. The second, Skills, shows you how to save the instructions for a task you do often, such as a weekly summary, so you can ask for it in one line. The third, Custom agents, shows you how to set Copilot up for a specific role, such as a reviewer, with its own instructions and only the tools that role needs. The fourth, Connecting your tools, shows you how to connect Copilot to another service, such as GitHub, so it can get information from there.

    You take each training at your own pace, in VS Code on your computer. Each training is made up of units, and each unit has a narrated video. If you run into a problem, the Help page explains what to do.

    Begin with Getting started, since every other training builds on it. Custom agents also builds on Skills, so take Skills before Custom agents.
