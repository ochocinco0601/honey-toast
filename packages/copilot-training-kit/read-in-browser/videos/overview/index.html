    About this video

    An overview of the trainings: what Copilot does in VS Code, how the trainings fit together, and where to start.

    Learn GitHub Copilot in VS Code is a set of short trainings. They teach you to hand work on your files to an AI assistant, asking in plain words, and you don't need to write code. Copilot works on the files on your computer from a chat beside them: ask for a one-page summary of a folder and the new file appears; to undo it, hover over your request, select Restore Checkpoint, then Yes. By default, it asks before it runs a command that could change something, because undo can't take back a command it has run. It works from instructions, what you tell it, and tools, what it's allowed to do: read a file, change a file, run a command.

    • Getting started teaches you to ask for work, change it and undo it, and custom instructions: notes Copilot reads before every request in that folder.
    • Skills is for a task you repeat, such as a weekly summary: save the steps once, then ask for the task.
    • Custom agents sets Copilot up for one role, such as a reviewer, with its own instructions and only the tools it needs.
    • Connecting your tools adds tools from another service, such as GitHub, so Copilot can look things up there.

    Start with Getting started. The Skills and Connecting your tools trainings both build on it, and Custom agents also builds on Skills.
