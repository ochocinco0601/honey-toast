# GitHub Copilot training

Trainings in handing real file work to GitHub Copilot, the assistant inside Visual Studio Code
(VS Code), and checking what it did. Each one works at your own pace, whether or not you attend a
live session. New to the assistant? Start with Getting started.

## The trainings

- [Getting started](getting-started/README.md): your first hour with the assistant. Start here if
  you are new.
- [Skills, in more depth](skills-in-depth/README.md): coming later.
- [Agents](agents/README.md): coming later.

## Reading these trainings

- **In a web browser:** in Windows File Explorer, open this folder, then `read-in-browser`, and
  double-click `README.html`. Every prompt there has a Copy button, and the side menu lists every
  page.
- **In VS Code:** click a page in the list on the left and press Ctrl+Shift+V to read it as a page.
  The `read-in-browser` pages open as code in VS Code; open them from File Explorer instead.
- **On GitHub:** the pages are already readable, and the links work.
- **Blanks** in a prompt, the parts in angle brackets such as `<your folder>`, are yours to
  replace, brackets included, before you press Enter.
