# What's new

## 1.7 - 2026-10-20

- Every lesson now has a narrated video beside its written steps, as its own item just before
  the lesson, from about two and a half to six minutes. Its outline entry reads "Video", each
  numbered step has a "Watch this step" link to its scene. The video plays on a page of the
  training, with the outline and breadcrumb, and "Next: Written steps" above it. The steps stay the
  complete instruction.
- The home page links to a new overview video of the trainings, about three minutes.
- Getting started, "Make your first request to Copilot": opening the practice folder now starts
  with the Restricted Mode bar that VS Code shows by default (**Manage**, then **Trust**), with a
  drawing of the bar. The question whether you trust the authors is now the exception.
- The same lesson, "Reading a permission request", says which changes Copilot makes without asking
  and which it asks about first.
- Skills, Custom agents and Connecting your tools open their practice folder the same way, with the
  same drawing. "Have Copilot explain code you didn't write", "On your own work", now says to trust
  the folder from the Restricted Mode bar.

## 1.6 - 2026-10-20

- The home page now says that the other trainings build on Getting started, and Custom agents also
  on Skills. It used to say that each training builds on the one before it.

## 1.5 - 2026-10-20

- Every page has a new look that shows where to start reading: the title with the size of the
  unit or training under it, a unit's steps on one line with a ring at each step, each prompt to
  copy on its own background with its **Copy** button, and a training's path as a sequence that
  shows which units you have finished. Text is set in a wider column.
- The words, units and steps are the same as in 1.4. If you already took a training, there is
  nothing to do again.

## 1.4 - 2026-10-07

- Every training has more drawings of VS Code: Open Preview in the menu of a file, New Chat, the
  file Copilot saved in the list on the left, going back to **Agent**, the handoff button, the
  line that starts a connection, and the tools Copilot ran. The list of agents now also shows
  New Chat.
- Skills, Custom agents and Connecting your tools show the permission request and the trust
  question again where each training first opens its folder.
- Skills, "What is a skill?", and Connecting your tools, "Connect Copilot to GitHub", have new
  diagrams: where a skill works, how a skill differs from custom instructions, and what a
  connection adds.
- Custom agents, "What is a custom agent?": the diagram of a tool asked for or taken away is
  redrawn to match, and the table comparing custom instructions, a skill and a custom agent is
  now a diagram with a list under it.
- Getting started, "Change Copilot's work, then undo it": the step that undoes the table names
  the **Yes** button.
- Every step that asks whether you trust a folder's authors says to leave the box about the
  parent folder unticked; Help says the list of agents opens with the selected agent
  highlighted.

## 1.3 - 2026-10-07

- Home page: a new "Which to use when" table. It shows when to use custom instructions, a skill, a
  custom agent or a connection, and which training teaches each.
- Custom agents, "What is a custom agent?": a custom agent is set up for a role, such as reviewer,
  planner or writer. Taking a tool away is one reason to use one, not the only one. The exercise
  has a fifth case.

## 1.2 - 2026-10-05

- Custom agents, "What is a custom agent?": the answer to the four cases lists each case on
  its own line.

## 1.1 - 2026-10-05

- Help, "Getting set up": install and update VS Code from your company's software portal, and sign
  in with your work GitHub account.
- In the menu on the left, **Practice recipes** opens to list each recipe, on every page of the
  training.

## 1.0 - 2026-10-03

- The first release: Getting started, Skills, Custom agents and Connecting your tools.
