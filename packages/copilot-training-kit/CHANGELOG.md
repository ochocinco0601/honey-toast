# What's new

## 1.3 - 2026-10-07

- Home page: a new "Which to use when" table. It shows when to use custom instructions, a skill, a
  custom agent or a connection, and which training teaches each.
- Custom agents, "What is a custom agent?": a custom agent is set up for a role, such as reviewer,
  planner or writer. Taking a tool away is one reason to use one, not the only one. The exercise
  has a fifth case.

  training.
