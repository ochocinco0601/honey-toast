# Practice files

Made-up files, with no real people, customers or systems in them, for practice.

- `notes/`: three weekly meeting notes, with decisions, action items and open questions.
- `tickets.csv`: a ticket export, twenty-five rows.
- `changes/`: three change requests awaiting approval, and a checklist to review them against.
- `skills/weekly-ticket-summary/`: an example skill, with the result it should produce.
- `skills-broken/`: three skills, each broken in one way, to practise fixing.
- `agents/`: three custom agents that read files but cannot change them.
