# How to: organize a messy folder

Assumes you have finished `README.md`: VS Code open, this training folder open, the chat in Agent
mode. About ten minutes.

**When:** your downloads folder, your desktop, a project folder that grew without a plan.

1. Add the folder to the workbench: menu File, then Add Folder to Workspace, then choose it. This
   kit stays open beside it. Adding a folder moves nothing.
2. Ask for a plan before any action. Wherever a prompt says `<your folder>`, type your folder's
   name; with two folders open, the assistant needs to be told which one.
   > List the files in `<your folder>` grouped by type and by month. Propose a folder structure. Do not move anything yet.
3. Read the plan. Change it in words:
   > Put all the vendor PDFs under `vendors/` instead.
4. Ask for the move:
   > Do it. Move the files as proposed and give me a table of what moved where.
5. Allow the commands. Watch the list on the left change.
6. Keep the record:
   > Save that table as `moves.md` in `<your folder>`.

**Check:** open two files where they landed.

**If it went wrong:** ask it to move the files back, and point it at `moves.md`, which records
where everything went. That record is why step 6 exists.
