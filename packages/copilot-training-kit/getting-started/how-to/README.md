# Recipes

More practice after the path. Each recipe is a worked example of one kind of file work, about ten
to fifteen minutes. Try the ones closest to your own work, with your own files or the practice
files. Each assumes you have done [Start here](../start-here.md).

| Kind of work | Recipe | You end with |
|---|---|---|
| A spreadsheet or export from a system | [Analyze an exported spreadsheet](analyze-an-export.md) | Tables you checked, in `analysis.md` |
| A folder of notes | [Turn a folder of notes into one summary](summarize-a-folder-of-notes.md) | `summary.md`, every item sourced |
| Documents someone handed you | [Find what is missing from documentation](find-what-is-missing-from-documentation.md) | `gaps.md`, questions to send back |
| A change or request to approve | [Review a change request for go or no-go](review-a-change-for-go-or-no-go.md) | `review.md`: go, no-go or ask, per change |
| A messy folder | [Organize a messy folder](organize-a-folder.md) | A sorted folder and `moves.md` |
| Many files to change the same way | [Change many files at once](change-many-files-at-once.md) | Changed copies, originals untouched |
| Standards you keep re-explaining | [Set house rules once](set-house-rules.md) | An instructions file it follows every time |
| A job you do every week | [Ask for a skill](ask-for-a-skill.md) | A skill file you run by name |
| Anything else | [Write your own request](write-your-own-request.md) | Your own request, checked |

By kind of work:

- **Supporting an application:** [Find what is missing](find-what-is-missing-from-documentation.md),
  [Change many files at once](change-many-files-at-once.md), and
  [Lesson: an application you do not own](../lesson-application.md).
- **Tickets, exports and notes:** [Analyze an export](analyze-an-export.md),
  [Summarize notes](summarize-a-folder-of-notes.md), [Organize a folder](organize-a-folder.md).
- **Managers and analysts:** [Review a change](review-a-change-for-go-or-no-go.md),
  [Find what is missing](find-what-is-missing-from-documentation.md),
  [Summarize notes](summarize-a-folder-of-notes.md).
