# Practice recipes

These recipes are optional practice for after you finish Getting started. Each is a new task that
uses what the training taught. Do any of them, in any order. Copilot creates the practice files for you.

| Kind of work | Recipe | You end with |
|---|---|---|
| An export from a system, as a CSV file | [Analyze an exported spreadsheet](analyze-an-export.md) | `analysis.md`, with counts and the oldest open tickets, and one figure you checked |
| Documents someone handed you | [Find what is missing from documentation](find-what-is-missing-from-documentation.md) | `gaps.md`, questions for the team that sent the documents |
| A change request to approve | [Review a change request for go or no-go](review-a-change-for-go-or-no-go.md) | `review.md`, with a suggested go, no-go or ask for more information for each change request |
| A folder that grew without a plan | [Organize a folder](organize-a-folder.md) | A sorted folder and `moves.md` |
| Many files that need the same change | [Change many files at once](change-many-files-at-once.md) | Updated copies of the files, with the originals unchanged |
