# Getting started

In this training, you make your first request to GitHub Copilot in VS Code. You change its work
and undo it, have it explain code, and give it instructions for a folder. You can then do the same
with your own files.

## What you will be able to do

- Have Copilot create files in VS Code, and approve the commands it asks to run when they match what you asked.
- Give Copilot a task that takes several actions, and change the result by asking again.
- Undo a change Copilot made.
- Have Copilot explain an application's code, and point you to the lines that do a particular job.
- Give Copilot custom instructions it follows with every request in a folder.

## Before you start

- A Windows computer with VS Code installed and signed in to GitHub Copilot. If either isn't
  ready, see [Getting set up](../troubleshooting.md#getting-set-up).
- If a button or menu has a different name on your screen, trust your screen: VS Code changes its
  labels. Ask Copilot what it's called now.

## The path

1. [Make your first request to Copilot](start-here.md): open the chat and have Copilot create a folder to practice in.
2. [Change Copilot's work, then undo it](lesson-your-files.md): have Copilot write meeting notes and an action list, change the list by asking again, and undo the change.
3. [Have Copilot explain code you didn't write](lesson-application.md): have Copilot build a small application, explain it, and point you to the lines that do a particular job.
4. [Give Copilot custom instructions for a folder](custom-instructions.md): have Copilot save custom instructions for summaries, and see the next summary follow them.

## After the path

Once you finish the path, you can try the [practice recipes](how-to/README.md). Each is an optional
new task that uses what this training taught. Do any of them, in any order.
