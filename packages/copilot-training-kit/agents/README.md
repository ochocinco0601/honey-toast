# Custom agents

A custom agent is Copilot set up for one role, such as reviewer or planner.
It has its own instructions, the tools it may use and, if you choose, its AI model. In this training, you
learn when to use one. Then you create a reviewer that can read files but not change
them, and give its reports a fixed layout.

## What you will be able to do

- Say what a custom agent is, and when to use one rather than custom instructions, a skill or
  just a request.
- Create a custom agent that can read files but not change them, and use it.
- Give a custom agent a fixed layout for its reports.

## Before you start

- You have finished [Getting started](../getting-started/README.md) and
  [Skills](../skills-in-depth/README.md).
- VS Code is open, and a control at the bottom of the chat box shows **Agent**.

## The path

1. [What is a custom agent?](what-is-a-custom-agent.md): what a custom agent is for, what one looks like, and how it differs from custom instructions and a skill.
2. [Create your first custom agent](create-your-first-custom-agent.md): have Copilot create a reviewer whose tools only read, use it on practice procedures, and see that it can't change them.
3. [Make a custom agent's reports consistent](make-its-reports-consistent.md): add a report layout to the reviewer's instructions, and get the same layout however you ask.

## After the path

Once you finish the path, you can try the [practice recipes](how-to/README.md). Each is an optional
new task that uses what this training taught. Do any of them, in any order.
