# Glossary

A word not here? Ask the assistant: "What does `<word>` mean here, in plain words?"

## On your screen

| Word | Meaning here |
|---|---|
| Agent mode | The chat setting in which the assistant can act, not only answer. Chosen with the mode selector |
| Chat | The panel where you talk to the assistant |
| Explorer, or the list on the left | The panel showing the open folders and their files. If it is missing: menu View, then Explorer |
| Mode selector | The small selector at the bottom of the chat box. It should say Agent |
| Permission request | The button inside a reply that asks whether the assistant may run a command on your computer. How to read one: [Reading a permission request](getting-started/start-here.md#reading-a-permission-request) |
| Preview | The readable view of a markdown page in VS Code. Ctrl+Shift+V opens it |
| Terminal | A panel at the bottom of the window where the commands the assistant runs show their output. You do not need to type there |
| VS Code | Visual Studio Code, the program the training runs in |
| Workspace | The folder, or folders, open in VS Code. The assistant reads and writes inside them. With two open, VS Code offers to save the pair under a name so you can reopen both |

## Working with the assistant

| Word | Meaning here |
|---|---|
| Blank | A part of a prompt in angle brackets, such as `<your folder>`, that you replace, brackets included, before pressing Enter |
| Check the receipts | Ask which files an answer came from, open one, and see whether it says that. An answer with no source is a guess |
| Chore | One piece of file work from start to finish: organize a folder, summarize a set of notes, analyze one export |
| Command | An instruction the assistant runs on your computer to do a job, such as creating a folder or moving files. It asks before running one |
| Copilot | GitHub Copilot, the assistant inside VS Code that this training is about. Not the assistant in your office suite |
| CSV | A plain-text spreadsheet export, and the format the assistant reads most reliably. Most systems that export to a spreadsheet can produce one |
| Export | A file a system gives you of its data, such as a list of tickets or changes |
| House rules | Your team's standards written once in an instructions file in your folder, so the assistant follows them without being told each time |
| Markdown | A plain-text format for documents. Raw, it shows # and * symbols; previewed, it reads like a page |
| New chat | A fresh conversation, started with the plus button at the top of the chat panel. It remembers nothing of earlier chats; the files do |
| Prompt | What you type or paste into the chat to ask for something |
| Skill | A text file of instructions that tells the assistant how to do a particular job your way |
| Workbench | The explanation page's word for VS Code with a folder open: a table you lay work out on and leave between sittings |

## Applications and code

| Word | Meaning here |
|---|---|
| Clone | Make a local copy of a repository |
| Code host | The shared system where repositories live, with their history and reviews. GitHub is one |
| Commit, pull request, merge | The steps by which a change is proposed, reviewed and accepted into the shared copy |
| Connector | A configured link that lets the assistant read a system directly instead of an export |
| Documentation generator | A tool some organizations provide that writes a set of pages about an application from its code |
| Extension | An add-on to VS Code, installed from a marketplace, like an app on a phone. The assistant is one |
| Git | The version-control program that copies a repository to your computer and tracks changes to it. The assistant runs it for you |
| Repository | An application's source code and supporting files, kept in a shared system |
