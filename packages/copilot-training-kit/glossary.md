# Glossary

A word not here? Ask Copilot what it means.

## On your screen

| Word | Meaning here |
|---|---|
| Agent | Copilot with a set of instructions and tools. You select one from the control at the bottom of the chat box. The one named **Agent** can create and change files and run commands |
| Chat | The panel where you type requests to Copilot. The chat box is the field at its bottom |
| Explorer | The list on the left of VS Code showing the open folder's files. If it's missing, on the View menu, select Explorer |
| Permission request | Allow and Skip buttons in a reply, asking whether Copilot may run a command. How to read one: [Reading a permission request](getting-started/start-here.md#reading-a-permission-request) |
| Preview | The formatted view of a Markdown file. In the list on the left, right-click the file and select Open Preview |
| Terminal | The panel at the bottom of VS Code where the commands Copilot runs show their output |
| VS Code | Visual Studio Code, the program you work in |

## Working with Copilot

| Word | Meaning here |
|---|---|
| Checkpoint | Your files as they were before a request. Restore Checkpoint on a request puts them back |
| Command | An instruction Copilot runs on your computer, such as creating a folder. It asks before running one that could change something |
| Copilot | GitHub Copilot in VS Code, which this training is about. Not Copilot in your office suite |
| Custom agent | An agent you have Copilot create, with your instructions and only the tools you choose. You select it in the chat box |
| Custom instructions | Notes Copilot reads before every request in a folder: what your work is, who it's for and how you want it done. Kept in `.github/copilot-instructions.md` |
| Follow-up | A request that builds on the last one in the same chat, so it can be short |
| Markdown | Plain text with simple marks for headings and lists, in a file ending `.md`. Its preview shows it formatted |
| MCP server | A connection that lets Copilot read or act on another system directly, instead of on a file exported from it |
| New Chat | A fresh conversation, started with New Chat (+) at the top of the chat. It doesn't remember earlier chats; the files stay |
| Request | What you type or paste into the chat to ask Copilot for something |
| Skill | Saved instructions for one kind of task, which Copilot follows when you ask for that task. A skill in a folder works while that folder is open; one in your personal skills folder works in every folder |
| Subagent | An agent Copilot hands part of a job to; it does that part and reports back |
| Tool | One action Copilot can take, such as reading a file, changing a file or running a command. An agent can do only what its tools allow |
