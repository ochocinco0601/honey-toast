# Connecting your tools

A connection lets Copilot get information that isn't in your files, from another service such as
GitHub. In this training, you connect Copilot to GitHub, and use the connection to look up a
public project on GitHub.

## What you will be able to do

- Say what a connection gives Copilot, and how you can tell when Copilot uses one.
- Add a connection to a folder and use it in a request.

## Before you start

- You have finished [Getting started](../getting-started/README.md).
- VS Code is open, and a control at the bottom of the chat box shows **Agent**.

## The path

1. [Connect Copilot to GitHub](connect-to-github.md): add a read-only connection to GitHub in a practice folder, and see Copilot use it to answer a question about a public project on GitHub.
