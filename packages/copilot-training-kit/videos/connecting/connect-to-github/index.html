    About this video

    The unit's steps, narrated: have Copilot create a practice folder, add GitHub's read-only connection and start it, then ask a question that uses it. Pause where the video says, do the step on your computer, then play on.

    This video walks through the unit's three written steps. If your screen doesn't match, the written steps say what to do.

    1. Have Copilot create a connections-practice folder, open it in VS Code, and trust it.
    2. Have Copilot add the GitHub connection in .mcp.json, start it, and sign in.
    3. In a new chat, ask about a public repository on GitHub, and find Ran List commits in the reply.
