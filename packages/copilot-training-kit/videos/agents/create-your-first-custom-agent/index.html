    About this video

    The unit's steps, narrated: have Copilot create practice procedures and a Procedure reviewer that can only read files, use it to check the procedures, and ask it to change one. Pause where the video says, do the step on your computer, then play on.

    This video walks through the unit's five written steps. If your screen doesn't match, the written steps say what to do.

    1. Have Copilot create practice procedures, and open their folder in VS Code.
    2. Have Copilot create the Procedure reviewer, and check its name and tools.
    3. Start a new chat, and select the Procedure reviewer.
    4. Have the Procedure reviewer check the procedures.
    5. Ask it to change a procedure, and see that it can't.
