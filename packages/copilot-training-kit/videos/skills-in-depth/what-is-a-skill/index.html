    About this video

    The Skills training's first unit, narrated: what a skill is, what its file holds, how Copilot picks one, where it works, and how it differs from custom instructions.

    This video narrates the unit's written page, which holds the same points and the button that completes the unit.

    1. Why use a skill? tasks you ask for again and again.
    2. What does a skill look like? a folder with a SKILL.md file, its header, then its instructions.
    3. How does Copilot use a skill? by its description, or by name with /.
    4. Where does a skill work? in one folder, or in every folder.
    5. How is a skill different from custom instructions? a skill is read only when a request matches it.
