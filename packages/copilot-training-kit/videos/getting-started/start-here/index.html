    About this video

    The first unit's steps, narrated: open VS Code and the chat, have Copilot create a practice folder, and open it. Pause where the video says, do the step on your computer, then play on.

    This video walks through the unit's three written steps. If your screen doesn't match, the written steps say what to do.

    1. Open VS Code and the chat, and check that the control at the bottom of the chat box says Agent.
    2. Have Copilot create a copilot-practice folder in Documents, and check it in File Explorer.
    3. Open the folder in VS Code, and trust it.
