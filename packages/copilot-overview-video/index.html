Learn GitHub Copilot in VS Code

    Learn GitHub Copilot in VS Code is a series of short trainings on handing work on your files to an AI assistant, in plain language, whether or not you write code. It works across a whole folder from a chat beside your files: ask for a one-page summary of the folder and the file appears. It asks before moving or deleting files, and the edits it makes inside your files can be undone. It works from what you tell it (your request, plus preferences it remembers) and what it is allowed to do (read files, change them, run commands). Getting started covers asking, undoing and custom instructions. Skills is for work you repeat, such as a weekly summary. Custom agents is for a dedicated helper, such as a reviewer that can only read your documents. Connecting your tools lets it look things up in another service your team uses, such as GitHub. Start with Getting started; the others build on it.
