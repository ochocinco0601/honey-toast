# Learn GitHub Copilot in VS Code: an overview

A narrated overview, about 2:02 long, of the trainings Learn GitHub Copilot in VS Code: what
each one is for and where to start. The trainings themselves are in `copilot-training-kit`, in this
same catalog. It comes in two versions with the same script and voice.

## The page version

Open `index.html` in a browser, with the `audio` folder kept beside it. It has captions you can turn
on and off, the transcript beside the player (click a line to play from it), and a step for each
scene. It also works with the sound off: it stops after each scene so you can read the caption.

## The video file

`copilot-trainings-overview.mp4` plays anywhere a video does and can be shared as a single file. Its
captions are built in, and the same captions are in `copilot-trainings-overview.vtt` for a player
that takes a separate captions file.
