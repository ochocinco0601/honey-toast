# A request, house rules, a skill, or an agent?

Keep this page. Ask the four questions in order and stop at the first yes.

| # | Ask yourself | If yes, use | Because |
|---|---|---|---|
| 1 | Will I do this only once or twice? | **A request** in the chat, with the five parts | Saving it costs more than writing it |
| 2 | Should it apply to everything I ask in this folder, whatever the job? | **House rules** (the instructions file) | The assistant reads them every time, without being asked |
| 3 | Is it one job I repeat, with a result that should look the same each time? | **A skill** | It is used when that job comes up, and does it the same way |
| 4 | Do I want to hand a whole kind of work to a role, limit what it may touch, and get a report back? | **An agent** | Its instructions and its permitted tools travel together |

If two seem to fit, choose the earlier one. A skill can also say what not to touch; choose an agent
when the limit must hold even if the instructions are misread.

## Worked cases

Decide each one yourself before reading the answer.

**1. Operations.** "Every summary I ask for should use our status words: Red, Amber, Green."
House rules. It is not one job; it applies to every summary in the folder (question 2).

**2. Operations.** "Every Monday I summarize last week's ticket export, the same way each time."
A skill. One job, repeated, and the result should have the same headings every week (question 3).
House rules would push that layout onto everything else in the folder.

**3. Operations.** "All week I want to ask different questions about our ticket exports, and be
sure nothing edits them."
An agent that can read but not change files. The questions differ, so there is no single job for
a skill, and the limit on changing files is the point (question 4).

**4. Managers and analysts.** "Tomorrow I need a comparison of two vendor proposals for one
meeting."
A request. It happens once (question 1). Write it with the five parts and check the result.

**5. Managers and analysts.** "Our fiscal year starts in October, and nothing we write should
recommend a vendor by name."
House rules. Both apply to everything written in the folder (question 2).

**6. Engineers.** "For each application I support, I want the same documentation sections, built
the same way from its code."
A skill. One job, repeated across applications, with a fixed shape of result (question 3). An
engineer may add a script to the skill for the parts that are mechanical.

**7. Engineers.** "Before I approve a change, I want it checked against our checklist, item by
item, by something that cannot alter the change request."
An agent, read-only. It is repeated, so a skill would almost fit, but the guarantee that it cannot
alter the file is what decides it (question 4).
