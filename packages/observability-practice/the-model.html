The methodology (Layer 1) is stable and platform-agnostic. Everything else is implementation that can vary by organization, tooling, and use case.

Layer 1

Methodology

The model on this page.

  • Platform-agnostic (works with any tooling)
  • Stable (rarely changes)
  • Conceptual (how to think, not how to implement)
Layer 2

Data Model

  • Format-agnostic (YAML, JSON, SQL, CSV all valid serializations)
  • Structure matters, not serialization format
  • Can extend for use cases (Layer 4) while preserving core structure
Layer 3

Production Systems

  • Independently implementable (can use any subset)
  • Tool-specific (each organization chooses their tools)
  • Consumes Layer 2 data model as input
  • Dashboard Factory
  • Alert Factory
  • Playbook Factory
  • Story Factory
  • Graph Factory
  • AI/RAG Factory
Layer 4

Use Cases

  • Use cases inform expansion (new fields) at Layer 2
  • Layer 1 methodology stays stable across all use cases
  • Different organizations may prioritize different use cases
  • Batch Job Observability
  • API Observability
  • Message Handler Observability
  • Workflow/UI Observability
Layer 5

Workflows

  • AI-assisted extraction lives here (reducing PO burden)
  • Different organizations have different workflow priorities
  • Workflows consume artifacts from Layer 3
  • Green Field Onboarding
  • Brown Field Extraction
  • Continuous Validation
  • Incident Response
  • Dependency Analysis
  • Compliance Auditing
